# Om Tour and Travels

A modern, responsive tourism and travel website for **Om Tour and Travels**.

The website is designed for road trips, tour packages, vehicle rentals, destination exploration, and travel enquiries.

> **Note:** This website does not include flight booking.

## 📁 Project Structure

```text
om-tour-and-travels/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run

No server or installation is required.

### Step 1

Download or copy all project files into one folder:

```text
om-tour-and-travels
```

### Step 2

Make sure these files are inside the folder:

```text
index.html
style.css
script.js
README.md
```

### Step 3

Double-click:

```text
index.html
```

The website will open in your browser.

Before publishing the website, update the sample information in `index.html`.

```text

```

and replace it with the actual business phone number.

### Email

Search for:

```text
info@omtourandtravels.com
```

and replace it with the actual business email.

### Address

Search for:

```text

```

and replace it with the actual business address.

### WhatsApp

Search for:

```text
https://wa.me/919876543210
```

and replace the number with the actual WhatsApp number.

Use the number with country code and without spaces or `+`.

```text

```

## 🖼️ Images

The current website uses online images from Unsplash.

If you want to use your own images, replace the image URLs in `index.html`.

For example:

```html
<img src="your-image.jpg" alt="Travel destination">
```

You can also create an image folder:

```text
om-tour-and-travels/
│
├── index.html
├── style.css
├── script.js
├── README.md
│
└── images/
    ├── hero.jpg
    ├── destination-1.jpg
    ├── destination-2.jpg
    └── destination-3.jpg
```

Then use:

```html
<img src="images/hero.jpg" alt="Travel">
```

## 📞 Booking Form

The booking form currently performs front-end validation and displays a success message.

It does **not** send the enquiry to a real database or email server.

For production use, connect the form to a backend service such as:

* PHP
* Node.js
* Firebase
* Supabase
* Form submission service
* Your own API
